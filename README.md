## 👋 안녕하세요. Spring 기반 백엔드 개발자를 목표로 성장 중인 박지성입니다.

단순한 기능 구현을 넘어,
**트래픽과 네트워크 환경을 고려한 최적의 아키텍처**를 고민합니다.

REST API 설계, 데이터베이스 모델링,  
AWS와 Docker를 활용해 안정적인 클라우드 인프라를 구축하고 배포한 경험이 있습니다.
